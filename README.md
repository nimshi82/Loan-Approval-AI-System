# Loan-Approval-AI-System
AI-based loan approval system with bias detection
# Explainable and Fair AI-Based Loan Approval System

## 📌 Project Overview
This project predicts whether a loan should be approved or rejected using machine learning. It also analyzes fairness and detects bias in decision-making.

## 🚀 Features
- Loan approval prediction using ML models
- Random Forest and Logistic Regression comparison
- Feature importance analysis
- Bias detection based on gender and other attributes
- Risk profiling of applicants

## 📊 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib

## 📁 Dataset Features
- Age
- Gender
- Income
- Credit Score
- Loan Amount
- Debt-to-Income Ratio

## 📈 Results
- Achieved ~92% accuracy
- Model shows minimal bias across gender groups

## ⚖️ Bias Analysis
The model was evaluated for fairness by comparing approval rates across demographic groups.

## ▶️ How to Run
1. Upload dataset
2. Run the notebook step-by-step
3. View predictions and analysis
